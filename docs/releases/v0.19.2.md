# v0.19.2 Access Failure Reporting and Research Guidance

## 概要

検索の取得失敗やアクセス停止を、調査結果と一緒に記録・報告する手順を整えたpatchリリースです。同梱の文献調査Skillと公開ガイドを更新し、既存のセッション記録を使って、確認できた範囲と次の調査経路を引き継げるようにしました。

## 主な変更

- **失敗した検索の記録**: 検索結果の記録が作られなかった場合も、同じ調査セッションの未確認事項と次の行動へ保存できます。実行可能なJSON例と、Markdown・JSONでの書き出し手順を追加しました。
- **部分成功と件数の報告**: 成功したsourceの候補・既存の選別・注記を保ち、失敗sourceの総ヒット数を「不明」として報告します。正常0件、検索未実施、公式画面で確認した件数の下限を分けます。
- **調査経路の判断**: 取得失敗の応答と原因の判断を分け、公開UIの条件・利用者許可・利用可能なtoolを確認する手順を示しました。明示的な禁止やCAPTCHA・WAF challenge、rate停止を観測した場合の停止条件も整理しました。
- **確認範囲の引き継ぎ**: 試した経路、観測日時、応答、判断根拠、未確認範囲、次の行動を、既存の検索概要・確認範囲・調査ログに残す例を追加しました。

## 更新方法・互換性

公開API・保存形式・依存関係を維持しています。MCPは30 tools・21 sources、Node.js 22以上です。今回の手順を利用するには、同梱Skillも0.19.2へ更新してください。通常のSkills更新は同名の配置を置き換えるため、個別編集は事前に退避します。

```bash
npx --yes jp-lit-mcp@0.19.2 --version
npx --yes jp-lit-mcp@0.19.2 install-skills codex
```

利用アプリに合わせて`codex`を`cursor`または`claude`へ変えます。[失敗時の記録・報告手順](https://github.com/itarunnn/jp-lit-mcp/blob/v0.19.2/skills/jp-lit-research/heuristics/failure-modes.md)、[デジコレ全文検索ガイド](https://github.com/itarunnn/jp-lit-mcp/blob/v0.19.2/docs/ndl-digital-collections.md)、[アプリ別導入](https://github.com/itarunnn/jp-lit-mcp/blob/v0.19.2/README.md#使うアプリを選ぶ)を参照してください。

## 検証

文書のJSON例を現行schemaへ通し、検索entryがない合成失敗から、セッション記録の保存とMarkdown・JSONの書き出し・読み戻しを確認しました。変更前後の6ケースの適用試験では、初回失敗、部分成功、条件を満たす公開UI、challengeによる停止、正常0件、一部観測後の停止を確認しています。

依存監査はhigh 1件・moderate 2件・low 3件を報告しています。[今回の監査結果と後続確認](https://github.com/itarunnn/jp-lit-mcp/blob/v0.19.2/docs/third-party-notices.md#0192の依存監査)へ記録し、依存の修正は別の作業として引き継いでいます。
