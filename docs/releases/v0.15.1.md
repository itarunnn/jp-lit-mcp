# v0.15.1 — 日本文学・日本史向けTEI利用ガイド

## 概要

日本文学・日本史の研究者がTEIの探索と構造読解を始められるように、利用文書とREADMEの入口を整える。更新した文書をnpm packageへ同梱する。

## 主な変更

- TEIの研究用途と、日本文学・日本史それぞれの依頼例を追加した。
- 導入から文書検査、構造一覧、抽出、参照点検まで、hashとlocatorを引き継ぐPowerShell 7の実行例を追加した。
- 原構造、読みの選択、参照点検結果の扱いと、主なエラーへの対応を説明した。
- READMEと使い方ガイドからTEI利用ガイドへリンクした。

## 互換性・利用条件

MCPの公開tool 30種・source 21種、TEI readerの4操作とapi_version 0.1を維持する。Node.js 22以上を使用し、TEI readerにはuvとPython 3.13.15が必要。MCPの通常起動はNode.jsだけで行える。

## 検証

2026年10月3日にWindows環境で確認した。

- lockfileに従う依存環境で85 files / 912 tests、Python readerの49 tests、build / scripts typecheck / offline MCP smokeを通過した。
- 0.15.1のtarballにREADME、TEI利用ガイド、使い方ガイドと本リリースノートが含まれ、非公開の研究資料が含まれないことを確認した。
- tarballをrepository外へ導入し、doctorと付属サンプルの4操作を通過した。
- 文書更新時に、文書から抽出したPowerShell例と公開済み0.15.0のreaderで4操作を実行した。原構造の保持と文書内参照の結果を確認した。

Windows / Ubuntu × Node22 / 24のGitHub CIとnpm公開workflowは、公開実行時に確認する。
