# v0.15.0 — 日本文学TEIの探索と構造読解

## 概要

jp-litで作品・書誌を探し、公開元から取得版を固定し、保存したTEIを構造と位置付きで読む導線を追加する。任意CLIとSkillを同じnpm packageに同梱する。

## 主な変更

- `jp-lit-tei` Skill: TEIの探索、取得台帳、hash/locator、原記述と解釈・確認状態の区別。
- `jp-lit-tei-reader` CLI: 文書検査、章・歌などの一覧、構造付き抽出、文書内参照の4操作。
- choice/subst/noteの各枝、属性、text/comment/PI順序を保持する。
- 参照点検にscope_xpathを追加。範囲内の参照を集計し、参照先IDと祖先xml:baseは全文書で確認する。
- XPath索引に累積16,777,216文字の上限を設け、長い祖先名によるメモリ増幅を構築中に抑える。
- Skills installerへ新Skillを追加。CIとnpm公開workflowへuv/Python・reader検証を追加。
- Windowsのpipe encodingに依存せず、日本語のCLIヘルプをUTF-8で表示する。
- npm依存関係の既知のadvisoryを解消し、開発用Vitestを4系へ更新。

## 互換性・注意

既存MCPの公開tool/sourceとNode.js22以上の利用条件を維持する。TEI readerの利用時にuvとPython3.13.15が必要。初回はuvがPythonをdownloadする場合がある。

readerは標準ライブラリのみを使う。要求/応答のapi_versionは0.1。scope省略/nullは全文書点検。XML元bytesは書き換えず、TEI schema検証、外部画像の取得・実見、底本校合は読解側の作業として残る。研究XMLや取得台帳、個人pathを配布物へ含めない。
