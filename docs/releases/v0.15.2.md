# v0.15.2 — TEI入門と読解・文献調査の往復

## 概要

TEIに初めて触れる日本文学・日本史の研究者が、公開データを探し、本文を読み、関連研究を調べて再読するところまで進められるように、利用ガイドとREADMEを整える。更新した文書をnpm packageへ同梱する。

## 主な変更

- TEIの正式名称、XMLとタグの意味、底本・編者・作成方針の確認方法を説明した。
- 漱石『こころ』の人物と発話、廣瀬本万葉集の歌本文・訓・訂正・書き入れを読む具体例を追加した。
- 本文から問いを立て、jp-litで文献を探し、確認できた論点を手掛かりに同じ箇所へ戻る手順を追加した。『こころ』の「淋しい」と万葉集の「内乃大野」を起点に、検索語・AIへの依頼文・研究ノートの残し方を示した。
- デジタル漱石、廣瀬本万葉集、校異源氏物語、延喜式の公開入口と、jp-litの書誌検索から公開元へ進む方法を案内した。
- READMEと使い方ガイドから、TEI入門と読解・文献調査の往復へ進めるようにした。

## 互換性・利用条件

MCPの公開tool 30種・source 21種、TEI readerの4操作とapi_version 0.1を維持する。Node.js 22以上を使用し、TEI readerにはuvとPython 3.13.15が必要。MCPの通常起動はNode.jsだけで行える。

公開TEIの探索は書誌検索と公開元の確認を組み合わせ、readerは保存済みXMLを処理する。検索語・依頼文は使い方の例で、実際の検索結果や先行研究の結論を示すものではない。書誌・要旨・本文の確認範囲を分け、本文・データ側の注釈・先行研究・自分の解釈を照合して使う。

## 検証

2026年10月3日にWindows環境で確認した。

- 85 files / 912 tests、Python readerの49 tests、build / scripts typecheck / offline MCP smokeを通過した。
- 固定公開XMLで『こころ』の章・節・人物・発話と、廣瀬本万葉集の歌本文・訓・訂正・注記を確認した。readerで4操作を実行し、往復例の出発点となる第七節と第4番を抽出できることを確認した。
- MCPの検索例6件を現行schemaでoffline確認し、文書内のリンクと見出しの参照を点検した。検索結果や未読の先行研究を作成していない。
- 独立レビューで、利用者の要件、公開元の一次案内、実資料、機能説明との一致を確認した。
