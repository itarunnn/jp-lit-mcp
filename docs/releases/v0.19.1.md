# v0.19.1 Search Reliability and Onboarding Fixes

## 概要

初めての導入から文献検索・結果確認へ進みやすくし、検索のページ送りとエラー判定、OCRの出典対応を修正した版です。公開API・保存形式・必要環境を保つpatchリリースです。

## 主な修正

- **検索結果のページ送り**: 国書DBが先頭結果を繰り返す問題と、国語研・国立公文書館・JACARで指定件数と上流のページ幅が異なると候補を飛ばす問題を修正しました。最終ページと範囲外も正しい区間を返します。
- **待機と検索エラー**: HTTPの本文受信にも同じタイムアウトを適用します。NDL SRUの診断エラーは検索失敗として伝え、正常な0件と区別します。
- **キャッシュ削除**: 現行・旧保存先に同じキーがある場合も両方を処理し、削除後に旧結果が再び使われる問題を修正しました。
- **OCRと画像領域の対応**: 同じページでも別領域のlocal OCR本文を関連付け・書き出しへ混ぜないよう、現在の出典と領域を照合します。変更・削除済み領域の候補は書き出しから除外し、理由を記録します。
- **Skillsの開始手順**: 文献検証の調査ID開始と受け渡しを補い、文献調査のレファ協検索より前にIDを開始する順へ揃えました。継続案件では同じIDを引き継ぎます。
- **インストーラー**: `install-skills codex --help`などのヘルプ指定と不正な引数では、既存Skillsを書き換えません。PowerShell・Unix wrapperは全引数と終了値を引き継ぎます。
- **初回利用の案内**: READMEをアプリ選択・Node/npm準備・短い依頼・成功確認の順へ整理しました。Codexの登録・有効化・接続確認、Cursor CLIの名称、作業ディレクトリを基準とする保存先、TEIの参照先も更新しました。

## 更新方法・互換性

MCPは30 tools・21 sources、Node.js 22以上を維持します。依存の追加や保存形式の変更はありません。CLIとSkillsを0.19.1へ揃えて更新してください。通常のSkills更新は同名の配置を置き換えるため、個別編集は事前に退避します。

```bash
npx --yes jp-lit-mcp@0.19.1 --version
npx --yes jp-lit-mcp@0.19.1 install-skills codex
```

利用アプリに合わせて`codex`を`cursor`または`claude`へ変えます。[アプリ別導入](https://github.com/itarunnn/jp-lit-mcp/blob/v0.19.1/README.md#使うアプリを選ぶ)、[機能別の必要環境](https://github.com/itarunnn/jp-lit-mcp/blob/v0.19.1/docs/install/runtime-requirements.md)も参照してください。

## 検証と継続事項

Node 140ファイル・1,364テスト、Python 91テスト、build・scripts型検査・offline MCP smoke、修正前の回帰再現と修正後の成功を確認しました。WindowsでskipとなるUnix wrapperの1件は、Git Bashで別途ヘルプと不正引数の書き込み0を確認しています。

依存監査は既知のhigh 1件・low 2件を引き継ぎます。Zod・Mirador/deepmergeの利用経路と後続対応は[依存監査の記録](https://github.com/itarunnn/jp-lit-mcp/blob/v0.19.1/docs/third-party-notices.md#0190の依存監査)を参照してください。
