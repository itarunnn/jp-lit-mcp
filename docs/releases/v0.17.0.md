# v0.17.0 — IIIF資料比較と出典付き画像読解

## 概要

複数機関の公開IIIF資料をローカル画面に並べ、選んだページ・矩形を画像と原テキスト、出典付きで既存AIアプリへ渡せるようにする。任意CLI `jp-lit-iiif`と4つ目のSkill `jp-lit-iiif`を同梱する。

## 主な変更

- Presentation 2/3の静止画像manifestを読み、1〜4窓で資料・ページを比較する。同じ資料の別ページ、拡大・移動・回転、配置と表示位置の保存・再開に対応する。
- Canvas座標の矩形、タグ、選択理由、注記をコレクションへ保存する。workspace JSONと初版profileの矩形AnnotationPageをexport/importできる。
- v3の単純な既存TextualBody、選択Canvasが明示する外部AnnotationPage最大1件、手動翻刻を扱う。原テキストとAIの補正候補を別に保存する。
- 1〜4領域の画像、原テキスト、`evidence.json`、`prompt.md`、`analysis-template.json`を利用者指定directoryへ書き出す。manifestとImage Service info.jsonの取得URL・時刻・hash、Canvas ID・矩形、原画像寸法と表示画像寸法、利用条件を残す。
- 同梱Mirador 4.2.6を使い、比較画面を127.0.0.1で起動する。起動tokenとHost/Originを確認し、選択範囲の公開HTTPS取得に容量・時間・redirect上限を設ける。
- README、各AIアプリの導入ガイド、IIIF/TEIガイドを4 Skillsとv0.17.0の導入にそろえる。

## 互換性と初版の範囲

MCPの公開tool 30種・source 21種、検索・session exportとTEI readerの契約を維持する。比較画面は任意CLIで起動し、MCPの通常起動にPython・OCR・ビューアは必要ない。Node.js22以上を使い、TEI readerを使う場合は従来どおりuvとPython3.13.15を用意する。

crop取得は単一の全Canvas paintingとImage API2/3 level1/2を対象とし、選択serviceのinfo.jsonから原寸法と対応版を確認する。JPEG/PNG、1件10MiB・16百万pixel・長辺2048pixel以内で取得する。複合画像・部分配置・未知service/selectorは診断を残す。IIIF Curation API全体や外部の任意Annotationとの完全互換は保証しない。

提供元の撮影条件・色・実寸は資料ごとに異なる。共通操作の比較画面で表示できても、等しい物理縮尺や色条件は保証しない。印刷頁とCanvas順序を分け、資料の利用条件と取得判断を記録する。認証・館内限定・送信限定資料の取得と全冊画像収集は対象外。

AI読解は利用中のアプリで画像を実際に開いて行う。生成した観察・翻刻候補・解釈は領域IDへ結び付け、原資料との校合を別に記録する。外部モデルやOCRへの自動送信は行わない。TEI facs/surface/zoneとの対応付け、くずし字OCR、モデル接続、類似図版・整列差分は後続段階である。

## 検証

2026年10月5日にWindows / Node24環境で確認した。

- Node 101 files / 990 tests、TEI reader 49 tests、build、scripts typecheck、offline MCP smokeを通過した。
- 国書DBとNDLの公開2資料で、3窓の比較、矩形・全頁選択、回転と配置変更、保存・再読み込み、片方の取得失敗時の他資料操作を確認した。
- 選択2画像を実取得・表示し、取得記録からの出典確認と、AI候補の領域ID2件の一致を確認した。試用ページに提供元の既存テキストはなく、この経路は合成fixtureによる契約検証で確認した。
- npm配布候補247 filesの取得範囲と同梱許諾文を点検し、研究資料・tests・cache・ローカル運用文書の混入がないことを確認した。repo外への新規導入でNodeのみのCLI/MCP起動、30 tools、3アプリ各4 Skills、比較画面asset配信を確認した。

AIの翻刻候補は原資料と未校合の読解補助である。画像取得とIDの一致は翻刻の正確さを保証しない。
